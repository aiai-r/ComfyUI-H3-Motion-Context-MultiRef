Release date: 2026-08-14

This release targets the post-#15439 native MiniMax H3 guide architecture and extends the repo's PR #15375-inspired AV target-latent masking path.

## Architecture

Normal Motion Context uses native #15439 `minimax_keyframes` and `cond_audio`. It does not use the old layout/payload monkeypatch architecture.

Masked extension/bridge features are different: source AV latents are written into the actual target latent and protected with a denoise mask. The repo uses native H3 AV-mask functionality when available and lazily installs its rebased #15375-equivalent compatibility only when required.

The compatibility is self-retiring: after native #15375-equivalent support appears, the model engine, mask preprocessing, inpaint scaling, and AV-mask payload extraction are left untouched. Payload detection uses bytecode/capability probes rather than source-text matching, including a native-hook fallback for refactored upstream implementations. Regression tests cover native no-op and legacy fallback paths.

## Mask semantics

- `0.0` = preserve the supplied target latent
- `1.0` = denoise / generate
